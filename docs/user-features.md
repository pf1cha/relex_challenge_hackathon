Website User Interface
Document List
Users should be able to view a list of all documents available to them and interact with those documents according to their permissions.
AI Chatbot
The website should include a chatbot where users can communicate with an AI assistant.
When responding, the chatbot may reference specific documents.
Document references should work similarly to modern AI chatbots:
A reference/citation icon should appear next to the relevant highlighted text.
When the user hovers over the reference or clicks it, a pop-up should appear or a side panel should open.
The pop-up/side panel should display:
A link to the referenced document.
The relevant quoted excerpt from the document.
When the user clicks the document link, the document should open in a new browser window or tab, provided that the user has permission to access it.
Visualization Window
The website should include a visualization section where users can select from the projects available to them.
After selecting a project, the user should be able to view the corresponding visualization and related information.
Admin Panel
This section should only be accessible to users with Admin-level permissions.
Administrators should be able to:
Activate or deactivate documents for AI agents, controlling whether AI agents are allowed to read and use those documents.
Permanently delete documents.
Delete client and employee information from the database.
Assign or associate clients and employees with specific projects.
Manage which users are assigned to which projects.
